# 构建管理客户端

这是一个现代化的 GUI 构建管理客户端，用于监控和管理自动化构建流程。

## 功能特性

### 🎨 现代化 GUI 界面
- **美观的 Dark 主题**：使用 customtkinter 构建的现代化界面
- **多标签页设计**：看板、日志、连接状态分门别类
- **响应式布局**：支持窗口缩放，适配不同屏幕尺寸

### 🌐 集成 Web 看板
- **一键打开管理看板**：直接在浏览器中打开服务器管理界面
- **连接状态监控**：实时显示与后端服务的连接状态
- **服务器地址显示**：清晰显示当前连接的服务器地址

### 📊 统计数据展示
- **项目统计**：显示各项目的构建次数排名
- **用户统计**：显示用户使用系统的频率统计
- **概览卡片**：总览项目数、构建次数、用户数等关键指标
- **可视化进度条**：直观展示数据占比

### 🔗 实时监控
- **SSE 连接状态**：实时显示服务器推送事件连接状态
- **连接健康检查**：定期检查与后端服务的连接状态
- **自动重连机制**：网络异常时自动尝试重新连接

### 📋 实时日志
- **实时日志显示**：在 GUI 中实时显示系统运行日志
- **日志级别过滤**：支持不同级别的日志显示
- **一键清空**：快速清理日志显示区域

### 🔔 通知集成
- **Windows 原生通知**：集成 win11toast 提供系统级通知
- **构建状态通知**：构建完成、失败等关键事件的及时通知
- **Toast 消息**：友好的消息提醒体验

## 安装和使用

### 环境要求
- Python 3.10+
- Windows 10/11 (推荐)
- 已安装项目依赖

### 安装依赖
```bash
# 安装完整依赖（包括 GUI 相关依赖）
uv sync --extra dev

# 或者仅安装基础依赖（无 GUI）
uv sync
```

### 启动应用

#### GUI 模式（推荐）
```bash
uv run manager-client
```

应用会自动检测运行环境：
- **Windows**：默认启动 GUI 模式
- **Linux**：检测到 DISPLAY 环境变量时启动 GUI 模式
- **macOS**：默认启动 GUI 模式
- **无 GUI 环境**：自动降级到 CLI 模式

#### CLI 模式
如果需要在无 GUI 环境下运行，应用会自动降级到命令行模式。

## 配置

### 环境变量
在项目根目录创建 `.env` 文件：

```bash
# 服务器地址
SERVER_HOST_URL=http://localhost:5005

# SSE 重连间隔（秒）
RECONNECT_INTERVAL=5
```

### 启动参数
目前应用通过环境变量进行配置，暂不支持命令行参数。

## 技术架构

### 主要组件
- **gui_main.py**：GUI 应用主入口
- **gui/main_window.py**：主窗口实现
- **gui/statistics_window.py**：统计窗口实现
- **client.py**：SSE 客户端实现
- **notifications.py**：Windows 通知实现

### 依赖管理
- **customtkinter**：GUI 框架（仅 dev 组）
- **pillow**：图像处理支持（仅 dev 组）
- **win11toast**：Windows 通知（仅 dev 组）
- **aiohttp**：异步 HTTP 客户端（仅 dev 组）

### 兼容性
- **服务端兼容**：GUI 依赖仅安装在 dev 可选组，不影响 Docker 部署
- **降级机制**：无 GUI 环境时自动降级到 CLI 模式
- **跨平台**：支持 Windows、Linux、macOS

## 开发说明

### 项目结构
```
src/manager_client/
├── __main__.py          # 主入口（支持 GUI/CLI 自动切换）
├── gui_main.py          # GUI 主入口
```

### 扩展开发
1. **添加新功能窗口**：在 `gui/` 目录下创建新的窗口类
2. **扩展统计功能**：在 `statistics_window.py` 中添加新的统计维度
3. **自定义主题**：修改 `gui_main.py` 中的主题设置
4. **添加新通知类型**：在 `notifications.py` 中扩展通知功能

### 注意事项
- GUI 相关依赖仅安装在 dev 可选组中
- 保持 CLI 模式的完整功能
- 确保跨平台兼容性
- 遵循现有的代码风格和架构

## 故障排除

### 常见问题

1. **GUI 无法启动**
   - 确认安装了完整依赖：`uv sync --extra dev`
   - 检查是否在支持的平台上运行
   - Linux 用户确认设置了 DISPLAY 环境变量

2. **连接失败**
   - 检查 `SERVER_HOST_URL` 配置是否正确
   - 确认后端服务正在运行
   - 检查网络连接和防火墙设置

3. **通知不显示**
   - 确认在 Windows 10/11 系统上运行
   - 检查系统通知设置是否启用
   - 确认安装了 win11toast 依赖

4. **统计数据加载失败**
   - 检查后端 API 服务是否正常
   - 确认网络连接稳定
   - 查看日志获取详细错误信息

### 日志查看
- GUI 模式：查看应用内的"📋 日志"标签页
- CLI 模式：查看控制台输出
- 详细日志：检查应用运行目录下的日志文件
